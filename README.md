# Data Engineering Projects

## About This Repository
This repository contains the data engineering projects I worked on while learning core big data and data engineering concepts.
The goal of this repository is to practice concepts through hands-on work and keep everything organized in one place.

Each folder represents a different topic I studied, starting from fundamentals and gradually moving to more advanced areas
like streaming, data lakes, and messaging systems.

## What’s Inside

### Hadoop Fundamentals
This section focuses on understanding Hadoop basics such as the MapReduce programming model and batch processing concepts.
It helped me understand how large datasets are processed in distributed systems.

---

### Spark Basics
Here I worked with Apache Spark using PySpark.
The projects include:
- Data analysis using Spark SQL and DataFrames  
- Graph processing using GraphFrames

This section helped me understand how Spark simplifies data processing compared to traditional MapReduce.

---

### ETL Pipeline
This section is focused on ETL concepts — extracting data, transforming it, and preparing it for analysis.
It represents how data pipelines work in real-world systems.
Some parts are still in progress and will be expanded further.

---

### Streaming Project
This folder contains a Spark Structured Streaming project.
I implemented a socket-based word count to understand how real-time data processing works,
including micro-batch execution and state handling.

---

### Data Lake and Hive
This section focuses on data lake concepts using Hive.
I worked with raw movie ratings data and used Hive SQL to analyze it using schema-on-read,
which is commonly used in data lake architectures.

---

### Kafka Basics
This section contains a Kafka producer–consumer project.
It helped me understand how event-driven systems work and how data flows through Kafka topics
using producers and consumers.
